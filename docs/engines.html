引擎

Hub 通过行业标准 ACP（stdio JSON-RPC）拉起上游 CLI。Shepaw 不改它们的行为，只把会话、模型、权限和终端代理到 App。目前内置 17 个公开引擎，目录由 Rust 主机维护。

Engines

Hub launches upstream CLIs over standard ACP (stdio JSON-RPC). Shepaw does not wrap their behavior — it proxies sessions, models, permissions, and the terminal into the app. There are 17 public built-in engines, and the catalog ships with the Rust host.

引擎目录是 Rust 主机内置的；上游 CLI（Claude Code、Codex、CodeBuddy Code 等）需你自行安装，Hub 不代装。用 shepaw instance engines --refresh 查看本机可用的引擎，shepaw instance add --engine <id> --cwd ~/work 注册实例。实例启动时主机按 ACP（stdio）拉起上游命令。

The engine catalog is built into the Rust host; install the upstream CLIs (Claude Code, Codex, CodeBuddy Code, …) yourself — the Hub does not install them. Run shepaw instance engines --refresh to see what is available on this machine, then shepaw instance add --engine <id> --cwd ~/work to register an instance. The host launches the upstream command over ACP (stdio) when the instance starts.

自定义引擎

Custom engines

当前 Rust 主机只提供内置引擎目录，暂不支持 hub.json 里的自定义引擎；请先用 shepaw instance engines --refresh 确认上游 CLI 是否被识别。

The Rust host currently ships a built-in engine catalog only; custom engines in hub.json are not supported. Check shepaw instance engines --refresh first to see whether your upstream CLI was detected.

模型、模式、权限

Models, modes, permissions

  • ACP configOptions（category model）映射到 App 的模型列表 / 切换
  • PAW_ACP_SESSION_MODE 在 session 创建或恢复后写入上游（Claude acceptEdits、Codex on-request 等）
  • 剩余 session/request_permission 默认问 App（PAW_ACP_APPROVAL_MODE=ask）
  • 上游 terminal/* 在 Hub 所在机器执行
  • ACP configOptions (category model) map to the app model picker
  • PAW_ACP_SESSION_MODE is applied after session new/resume (Claude acceptEdits, Codex on-request, …)
  • Remaining session/request_permission calls default to the app (PAW_ACP_APPROVAL_MODE=ask)
  • Upstream terminal/* runs on the Hub host

凭据

Credentials

在 App 的「设置 → 引擎管理」里配置，或给实例设置环境变量（ANTHROPIC_API_KEY、CURSOR_API_KEY …）。引擎没就绪时创建/启动实例会失败。

Configure them under Settings → Engines in the app, or use instance env vars (ANTHROPIC_API_KEY, CURSOR_API_KEY, …). Creating or starting an instance fails if the engine is not ready.
