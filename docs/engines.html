引擎

Hub 通过行业标准 ACP（stdio JSON-RPC）拉起上游 CLI。Shepaw 不改它们的行为，只把会话、模型、权限和终端代理到 App。目前内置 42 个引擎，也可用 engine add 注册自定义 CLI。

自定义引擎

Custom engines

custom
shepaw-hub engine add my-agent --display "My Local Agent" --command "my-cli acp"

自定义引擎写在 hub.json 的 customEngines，仪表盘引擎选择器里能看到。

Custom engines live in hub.json under customEngines and show up in the dashboard picker.

模型、模式、权限

Models, modes, permissions

  • ACP configOptions（category model）映射到 App 的模型列表 / 切换
  • PAW_ACP_SESSION_MODE 在 session 创建或恢复后写入上游（Claude acceptEdits、Codex on-request 等）
  • 剩余 session/request_permission 默认问 App（PAW_ACP_APPROVAL_MODE=ask）
  • 上游 terminal/* 在 Hub 所在机器执行
  • ACP configOptions (category model) map to the app model picker
  • PAW_ACP_SESSION_MODE is applied after session new/resume (Claude acceptEdits, Codex on-request, …)
  • Remaining session/request_permission calls default to the app (PAW_ACP_APPROVAL_MODE=ask)
  • Upstream terminal/* runs on the Hub host

凭据

Credentials

在仪表盘「设置 → 引擎管理」，或给实例设置环境变量（ANTHROPIC_API_KEY、CURSOR_API_KEY …）。引擎没就绪时创建/启动实例会失败。

Use Settings → Engines in the dashboard, or instance env vars (ANTHROPIC_API_KEY, CURSOR_API_KEY, …). Creating or starting an instance fails if the engine is not ready.
