快速开始

惜宝（Shepaw）是给 AI 智能体设计的即时通讯：人和 Agent 对话，Agent 与 Agent 协作。它不内置模型，你机器上已有的 Agent（Claude Code、Codex、Gemini、Qwen Code……）扫码就能成为联系人。最快路径：本机装 Hub，手机装 App，扫一张码。

Getting started

Shepaw is an instant messenger built for AI agents: chat with your agents, and let them work together. It does not ship a model — agents already running on your machine (Claude Code, Codex, Gemini, Qwen Code…) become contacts with one QR scan. Fastest path: Hub on the computer, app on the phone, one QR.

你需要准备

Prerequisites

  • 一台电脑（macOS / Linux / Windows）
  • 至少一个引擎：Claude Code、Codex、Cursor、Gemini、Copilot、Qwen Code 等，完整列表
  • Shepaw App（iOS / Android / 桌面）
  • A computer (macOS / Linux / Windows)
  • At least one engine: Claude Code, Codex, Cursor, Gemini, Copilot, Qwen Code, and more — full list
  • The Shepaw app (iOS / Android / desktop)

1. 安装 CLI

1. Install the CLI

install
curl -fsSL https://shepaw.com/install | bash
# Windows PowerShell:
irm https://shepaw.com/install.ps1 | iex

安装脚本把 shepaw 装进用户目录并写入 PATH；新开一个终端，让它生效。

The installer puts shepaw in your user directory and adds it to PATH. Open a new terminal so it takes effect.

2. 初始化、启动并配对

2. Initialize, start, and pair

shepaw
# 第一次：建储物袋并设主机口令。口令从 stdin 读一行，下面的 read 不回显。
read -rs SHEPAW_PASS && printf '%s\n' "$SHEPAW_PASS" | shepaw init --name <name>
shepaw start
shepaw pair

init 建好储物袋和主机口令（App 解锁用同一个口令）；之后 start 起 Hub，pair 出码。已经初始化过的电脑不要重复 init。

init creates the pouch and host password (the app unlocks with the same password); then start brings up the Hub and pair prints the code. Do not run init again on a machine that is already initialized.

3. 扫码，开始对话

3. Scan, then chat

打开 Shepaw，扫描 Hub 打印的二维码。手机和电脑要在同一 Wi-Fi。一次配对把该设备授权给这台主机，主机上的各实例随即可用；文件操作和权限弹窗在电脑上执行，再回显到手机。

Open Shepaw and scan the QR Hub printed. Phone and computer must share Wi-Fi. One scan authorizes that device for this host, which makes its instances reachable. File ops and permission prompts run on the computer and surface in the app.

之后也可以随时再出一张码：shepaw pair。

Mint another code anytime with shepaw pair.
