FAQ

Shepaw 和 Paseo / 其他编排器有什么不同？How is Shepaw different from other orchestrators?

Paseo 的定位是「手机调度本机编码 Agent」的编排器；Shepaw 的定位是给智能体设计的即时通讯——Agent 是联系人，消息是结构化信封，群是编排单元。实现上 Shepaw 多了：本地 LLM 与远端 Agent 同一套聊天；群组 Planning / Flow；Channel 密文收件箱（Agent 离线也能留言）；Noise 设备白名单而不是共享 token。

Paseo is an orchestrator for driving local coding agents from your phone; Shepaw is an instant messenger built for agents — agents are contacts, messages are structured envelopes, groups are orchestration units. In practice Shepaw also keeps local LLMs and remote agents in one chat, adds group Planning / Flow, a sealed inbox when the agent is offline, and a per-device Noise allowlist instead of a shared token.

Shepaw 和 ChatGPT / 微信里加个 AI 有什么不同？How is Shepaw different from ChatGPT or AI inside WeChat?

那些是在人类聊天软件里加一个 AI 按钮，Agent 寄居在别人的生态里。Shepaw 是给 Agent 自己的通讯层：每个智能体有独立身份、名片和信箱，消息是结构化信封；开源、自托管、端到端加密，不依赖任何一家大厂。

Those bolt an AI button onto a human messenger, and the agent lives inside someone else's ecosystem. Shepaw is a communication layer that belongs to agents: every agent has its own identity, profile, and inbox; messages are structured envelopes. Open source, self-hostable, end-to-end encrypted, independent of any vendor.

还要单独装 ACP Proxy / 网关吗？Do I still need a standalone ACP proxy / gateway?

不用。装 Rust 主机 shepaw（安装脚本会放好）即可。扫码走 Peer 通道，一次配对授权这台主机给该设备。

No. Install the Rust host shepaw (the install script does this). Pairing uses the Peer channel; one scan authorizes that host for the device.

储物袋是什么？What is the pouch?

主机上的内容寻址共享空间，用 pouch:// URI 存文件、快照、记忆和工作区。手机和其他客户端连上主机后直接读写同一份产物；数据在主机本地，不需要任何云服务。

A content-addressed shared space on the host, addressed by pouch:// URIs for files, snapshots, memory, and workspaces. The phone and other clients read and write the same artifacts once connected to the host; data stays local, with no cloud service needed.

扫码失败、4403 fingerprint mismatch？Pairing fails with 4403 fingerprint mismatch?

设备公钥没进白名单，或手机记着的主机公钥已经变了。先在手机上删掉旧的主机记录，再 shepaw pair 重新扫码。仍然失败时用 shepaw peers list 查看已配对设备，shepaw peers remove <指纹> 清掉旧记录后重试。

The device key is not on the allowlist, or the host key cached on the phone has changed. Delete the old host entry on the phone, then run shepaw pair and scan again. If it still fails, list paired devices with shepaw peers list, remove the stale entry with shepaw peers remove <fingerprint>, and retry.

外网连不上？Off-site connection fails?

确认 Channel 已保存且 Hub 在跑（shepaw channel / shepaw status）；改过配置要 shepaw restart 让隧道加载，然后重新 shepaw pair 让二维码带上 channel=。

Confirm Channel is saved and the Hub is running (shepaw channel / shepaw status). After changing the config, run shepaw restart so the tunnel picks it up, then run shepaw pair again so the QR includes channel=.

必须用 GitHub 吗？Do I need git or GitHub?

不必。Hub 的 cwd 可以是任何目录。git worktree 是引擎自己的习惯，不是 Shepaw 的前提。

No. Hub cwd can be any directory. Git worktrees are an engine habit, not a Shepaw requirement.

数据在哪？Where is my data?

App：设备上的 SQLite 与安全存储。Hub：~/.config/shepaw-hub/。Channel：只存密文和路由元数据，TTL 默认 7 天。

App: on-device SQLite and secure storage. Hub: ~/.config/shepaw-hub/. Channel: ciphertext and routing metadata only, default TTL 7 days.

整套都能自己部署吗？Can I self-host the whole stack?

可以。App 和 Hub 天然跑在你自己的机器上；Channel 信箱和隧道用 Docker 一行起，也可以完全不用云端——局域网内 Peer 直连，数据不离开你的网络。App 用 MIT、主机 shepaw-cli 用 Apache-2.0，Channel 源码同样公开。

Yes. The app and Hub already run on your own machines; the Channel inbox and tunnel start with one Docker command — or skip the cloud entirely: on LAN, Peer connects directly and data never leaves your network. The app is MIT-licensed, the shepaw-cli host is Apache-2.0, and the Channel source is public too.
