FAQ

Shepaw 和 Paseo / 其他编排器有什么不同？How is Shepaw different from other orchestrators?

同样是「手机调度本机编码 Agent」。Shepaw 多了：本地 LLM 与远端 Agent 同一套聊天；群组 Planning / Flow；Channel 密文收件箱（Agent 离线也能留言）；Noise 设备白名单而不是共享 token。

Same job: drive local coding agents from your phone. Shepaw also keeps local LLMs and remote agents in one chat, adds group Planning / Flow, a sealed inbox when the agent is offline, and a per-device Noise allowlist instead of a shared token.

Python SDK 能连现在的 App 吗？Can the Python SDK talk to the current app?

还不能。TypeScript SDK 与 Flutter App 已切到 ACP v2.1（Noise IK）。Python SDK 仍是 v1 明文协议，移植完成前请用 TypeScript 网关 / Hub。

Not yet. The TypeScript SDK and Flutter app speak ACP v2.1 (Noise IK). The Python SDK is still v1 plaintext — use the TypeScript gateway / Hub until it is ported.

扫码失败、4405 unauthorized peer？Pairing fails with 4405 unauthorized peer?

设备公钥没进白名单。重启 Peer：shepaw-hub peer-stop && shepaw-hub peer-start。Hub 启动 Peer 时会把 Peer 公钥写入各实例的 authorized_peers.json。

The device key is not on the allowlist. Restart Peer: shepaw-hub peer-stop && shepaw-hub peer-start. Starting Peer writes its public key into each instance’s authorized_peers.json.

外网连不上？Off-site connection fails?

确认 Channel 已保存且隧道路由器在跑（shepaw-hub gateway-status），然后重新 peer-pair 让二维码带上 channel=。

Confirm Channel is saved and the tunnel router is up (shepaw-hub gateway-status), then peer-pair again so the QR includes channel=.

必须用 GitHub 吗？Do I need git or GitHub?

不必。Hub 的 cwd 可以是任何目录。git worktree 是引擎自己的习惯，不是 Shepaw 的前提。

No. Hub cwd can be any directory. Git worktrees are an engine habit, not a Shepaw requirement.

数据在哪？Where is my data?

App：设备上的 SQLite 与安全存储。Hub：~/.config/shepaw-hub/。Channel：只存密文和路由元数据，TTL 默认 7 天。

App: on-device SQLite and secure storage. Hub: ~/.config/shepaw-hub/. Channel: ciphertext and routing metadata only, default TTL 7 days.
