App 功能

Shepaw 客户端（iOS / Android / macOS / Windows）是控制面：本地 LLM、远端编码 Agent、群组编排、储物袋，数据默认留在本机。

App

The Shepaw client (iOS / Android / macOS / Windows) is the control plane: local LLMs, remote coding agents, group orchestration, Store. Data stays on device by default.

两种 Agent

Two kinds of agent

  • 本地 LLM：OpenAI、Claude、Gemini、DeepSeek、Qwen、GLM、Kimi、Ollama，或任意 OpenAI 兼容 API。密钥只存在本机。
  • 远端 Agent：经 Peer 协议（/peer/ws）连到本机主机 shepaw-cli。扫码配对，见 配对。
  • Local LLM: OpenAI, Claude, Gemini, DeepSeek, Qwen, GLM, Kimi, Ollama, or any OpenAI-compatible API. Keys stay on device.
  • Remote agent: connects to the local host shepaw-cli over the Peer protocol (/peer/ws). QR pairing — see pairing.

聊天

Chat

Markdown、代码高亮、图片 / 文件 / 语音、流式输出、回复与搜索。远端 Agent 还可以弹出表单、确认按钮、权限请求。

Markdown, code highlight, images / files / voice, streaming, reply and search. Remote agents can also send forms, confirmations, and permission prompts.

群组编排

Group orchestration

  • Standard — Admin 轮流协调，最多 50 轮Admin coordinates round-robin, up to 50 rounds
  • Planning — 先出 JSON 计划，你逐条审批再执行JSON plan first; you approve tasks one by one
  • Flow — 分阶段自动跑，可暂停 / 跳步 / 中止Staged automatic run; pause / skip / abort

储物袋与技能

Store and skills

工作区文件、备份快照在储物袋。配对后的不同端 Agent 可以跨设备读写同一份产物（store:// URI，经 Peer 通道同步，不需要云服务）。技能包可从 ZIP 或 URL 导入。备份入口在「储物袋 → 备份与恢复」，加密快照，恢复是全量替换。

Workspace files and backup snapshots live in Store. Paired agents can read and write the same artifacts across devices (store:// URIs synced over the Peer channel, no cloud needed). Skills import from a ZIP or URL. Backups are under Store → Backup; snapshots are encrypted and restore replaces everything.
