Agent Hub

Hub 是本机（或 VM）上的多项目监督器：Rust 写的 shepaw-cli 为每个仓库拉起编码 Agent，通过 /peer/ws 与手机 App 通信，可选 Channel 做外网隧道。控制面是 App，主机没有独立的 Web 仪表盘。

Agent Hub

Hub is a multi-project supervisor on your machine or VM. The Rust workspace shepaw-cli starts a coding agent per repo, talks to the phone app over /peer/ws, and can use Channel as an off-LAN tunnel. The app is the control plane; the host has no separate web dashboard.

配置目录：~/.config/shepaw-hub/（SHEPAW_HUB_HOME 可覆盖）。

设备授权

Device authorization

shepaw pair 生成有效期 5 分钟的一次性配对码与二维码；手机扫码后按公钥加入白名单，握手用 Noise_IK_25519_ChaChaPoly_BLAKE2b。也可用 shepaw device invite / shepaw device revoke 管理设备。没有浏览器仪表盘，也没有仪表盘 token。

shepaw pair prints a one-time code and QR valid for five minutes; after scanning, the device is allowlisted by public key with a Noise_IK_25519_ChaChaPoly_BLAKE2b handshake. Use shepaw device invite / shepaw device revoke to manage devices. There is no browser dashboard and no dashboard token.

外网

Off-site

channel
shepaw channel set \
  --server https://channel.shepaw.com \
  --id ch_xxx \
  --secret <hmac-secret>
# channel set 会连上正在运行的 Hub；改完配置用 shepaw restart
shepaw pair        # 二维码同时带 local= 与 channel=

高级 tunnel 三项必须同时填写或全部留空。详见 Channel。

The three advanced tunnel fields must all be set or all empty. See Channel.
