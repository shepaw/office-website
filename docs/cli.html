CLI 参考

日常只用 shepaw-hub。装好后 quickstart 或 web，扫码即可。

CLI reference

Day to day you only need shepaw-hub. After install, run quickstart or web, then scan.

shepaw-hub

hub
shepaw-hub init
shepaw-hub doctor
shepaw-hub quickstart
shepaw-hub web [--host 127.0.0.1] [--port 4000] [--no-peer] [--no-open]
shepaw-hub update [--check] [--yes]

shepaw-hub engine list
shepaw-hub engine install <engine-id>
shepaw-hub engine add <id> --display NAME --command "cli acp"

shepaw-hub instance add [--engine claude-code] [--cwd PATH] [--host 0.0.0.0]
shepaw-hub instance-list
shepaw-hub start <id>
shepaw-hub logs <id> [-f]

shepaw-hub pair
shepaw-hub peer-start | peer-stop | peer-status
shepaw-hub gateway-set-channel --server URL --channel-id ID --secret SECRET
shepaw-hub test <id> [--rpc]

shepaw-hub pair 打印 Peer 二维码，一次授权本机全部实例。外网 Channel 见 Channel。

shepaw-hub pair prints a Peer QR and authorizes every instance on this host. Off-site Channel is covered in Channel.
