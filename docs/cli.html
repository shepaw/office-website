CLI 参考

主机是 Rust 写的 shepaw-cli，装好后的命令叫 shepaw。start 起后台 Hub，pair 打印配对二维码。

CLI reference

The host is the Rust workspace shepaw-cli; the installed command is shepaw. Run start for the background Hub, then pair to print the pairing QR.

shepaw

host
shepaw start
shepaw status [--json]
shepaw logs [--tail 50]
shepaw doctor
shepaw restart | stop
shepaw update [--check] [--yes]

shepaw pair [--local ws://<lan-ip>:<port>/peer/ws] [--channel <url>]
shepaw instance add --engine claude-code --cwd ~/work [--label NAME]
shepaw instance list
shepaw instance engines [--refresh]

shepaw channel set --server https://channel.example.com --id <channel-id>
shepaw channel                 # 查看当前 Channel 配置
shepaw peer serve              # 前台监听 /peer/ws（一般由 start 代管）

shepaw pair 生成一次性配对码，手机扫码后按公钥加入白名单。外网 Channel 见 Channel。工作节点用 shepaw join '<票据>' 与 shepaw node instance add。

shepaw pair prints a one-time pairing code; after scanning, the device is allowlisted by public key. Off-site Channel is covered in Channel. Worker nodes use shepaw join '<ticket>' and shepaw node instance add.

从源码跑

From a source checkout

shepaw-cli
git clone https://github.com/shepaw/shepaw-cli.git
cd shepaw-cli
cargo build --release -p shepaw-cli
./target/release/shepaw start
./target/release/shepaw pair

旧的 TypeScript 主机 agent-bridge 已废弃，不要再克隆或参照它。

The old TypeScript host agent-bridge is deprecated — do not clone or use it as a reference.
