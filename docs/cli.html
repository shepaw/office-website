CLI 参考

两套命令：多项目用 shepaw-hub，单进程网关用 shepaw-acp-proxy。

CLI reference

Two CLIs: shepaw-hub for many projects, shepaw-acp-proxy for a single gateway process.

shepaw-hub

hub
shepaw-hub init
shepaw-hub doctor
shepaw-hub quickstart
shepaw-hub web [--host 127.0.0.1] [--port 4000] [--no-peer] [--no-gateway] [--no-open]
shepaw-hub update [--check] [--yes]

shepaw-hub engine list
shepaw-hub engine install <engine-id>
shepaw-hub engine add <id> --display NAME --command "cli acp"

shepaw-hub instance add [--engine claude-code] [--cwd PATH] [--host 0.0.0.0]
shepaw-hub instance-list
shepaw-hub start <id>
shepaw-hub logs <id> [-f]

shepaw-hub peer-start | peer-stop | peer-status | peer-pair
shepaw-hub gateway-set-channel --server URL --channel-id ID --secret SECRET
shepaw-hub gateway-start | gateway-status
shepaw-hub pair <id> [--label NAME]
shepaw-hub test <id> [--rpc]

shepaw-acp-proxy

proxy
shepaw-acp-proxy serve --engine claude-code --cwd ~/project --host 0.0.0.0
shepaw-acp-proxy pair
shepaw-acp-proxy peers list
shepaw-acp-proxy peers add <pubkey> --label "My iPhone"
shepaw-acp-proxy peers remove <fingerprint>

From a source checkout

agent-bridge
git clone https://github.com/shepaw/agent-bridge.git
cd agent-bridge
npm install && npm run build
node implementations/acp-proxy-ts/dist/cli.js serve --engine claude-code --cwd ~/project
node agent-hub/cli/dist/cli.js web
